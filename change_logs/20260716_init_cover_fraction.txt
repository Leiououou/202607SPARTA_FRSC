================================================================================
变更日志: init_cover 支持部分覆盖度参数
================================================================================
日期: 2026-07-16
文件: src/surf_react_adsorb.h, src/surf_react_adsorb.cpp

--------------------------------------------------------------------------------
1. 问题描述
--------------------------------------------------------------------------------

此前 init_cover 关键词只接受一个参数（物种名），始终将表面所有位点填满（100%
覆盖度）。无法指定部分覆盖的初始条件。

--------------------------------------------------------------------------------
2. 修改内容
--------------------------------------------------------------------------------

修改 1: 头文件新增成员变量 (surf_react_adsorb.h:55)
  + double init_cover_fraction;  // 初始覆盖比例 (0~1), 默认1.0

修改 2: 构造函数初始化 (surf_react_adsorb.cpp:153)
  init_cover_fraction = 1.0;

修改 3: 解析覆盖度参数 (surf_react_adsorb.cpp:160-163)
  物种名之后直接读取第二个数字参数作为 fraction:
    init_cover_fraction = input->numeric(FLERR,arg[iarg]);
  校验 0 ≤ fraction ≤ 1，超出报错。

修改 4: FACE 模式执行 (surf_react_adsorb.cpp:607-610)
  maxstick → cover_count = round(maxstick * init_cover_fraction)
  打印信息改为 "Init_cover: XX% sites filled with <species>"

修改 5: SURF 模式 — local arrays (surf_react_adsorb.cpp:716-719)
  同上: maxstick → cover_count

修改 6: SURF 模式 — owned arrays (surf_react_adsorb.cpp:730-744)
  同上: distributed/non-distributed 两个分支均改为 cover_count

修改 7: 更新现有测试输入文件
  init_cover O → init_cover O 1.0 (7个输入文件)

--------------------------------------------------------------------------------
3. 语法变更
--------------------------------------------------------------------------------

旧格式 (已废除):
  init_cover O

新格式 (两个必选参数):
  init_cover O 1.0    ← 100% 覆盖
  init_cover O 0.5    ← 50% 覆盖
  init_cover O 0.0    ← 0% 覆盖（等价于不加）

--------------------------------------------------------------------------------
4. 关键设计决策
--------------------------------------------------------------------------------

- 两个参数均为必选，无需向后兼容旧格式
- 用 round() 取整，比 ceil/floor 更公平
- total_state = cover_count，空位 = maxstick - total_state 自动正确
- owned arrays 同步修改，确保 update_state_surf 正确重建

--------------------------------------------------------------------------------
5. 影响范围
--------------------------------------------------------------------------------

- 仅影响 init_cover 关键字的解析和执行
- 不影响反应概率计算（n(S) 因子自动使用 total_state 推导空位数）
- 不影响 tally_only、schu 等其他关键词

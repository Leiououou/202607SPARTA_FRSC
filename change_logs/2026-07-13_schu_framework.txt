    if (iarg < narg && strcmp(arg[iarg],"schu") == 0) {
      iarg++;

六、遇到的问题与修复
-----------------------
[问题1] schu 关键词位置逻辑错误
  描述: 初始版本在 "iarg += 5" 之前检测 schu，
        此时 arg[iarg] 指向的是 "nsync" 字符串而非 schu 或物种名，
        导致检测永远失败。
  修复: 将 schu 解析代码移到 "iarg += 5" 之后执行，
        此时 arg[iarg] 正确指向第一个物种名或 schu 关键词。

[问题2] 首次尝试用 mingw32-make 编译失败
  描述: Windows Git Bash 环境下没有 mpic++ 编译器
  修复: 改用 WSL Ubuntu-20.04 环境（用户告知 SPARTA 应在 Linux 编译）

[问题3] 直接用 Obj_mpi/Makefile 编译失败
  描述: ar 命令报错，因为 OBJ 和 EXE 变量未传递
  修复: 改用根目录 Makefile: "make mpi"，正确传递 OBJ/EXE 等变量

七、默认行为影响分析
-----------------------
- 不写 schu 关键词: 与修改前完全一致，走原 react() 函数，零影响
- 写入 schu no: 同上
- 写入 schu yes: 走 react_gs_finite_rate()（当前逻辑与原 react() 相同，
  概率公式尚未修改，无实际效果差异）

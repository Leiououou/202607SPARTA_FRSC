--------------------------------------------------------------------------------
1. 问题描述
--------------------------------------------------------------------------------

AA、DA、LH1、LH3、CD 五个吸附介导反应在微观概率计算中需要乘上空位点 S 的
数密度 n(S) 的幂次。n(S) 的幂次由 surf 输入文件中参数行最后一个数字指定
（即 coeff[3]，也称 n_adsorb）。

修正前:
- AA: 硬编码 n(S)^1（在 case 内部直接乘）；coeff[3] 被忽略
- DA: 硬编码 n(S)^2（在 case 内部直接乘）；coeff[3] 被忽略
- LH1/LH3/CD: 完全没有 n(S) 因子 ← BUG

虽然 AA 和 DA 硬编码的幂次与 coeff[3] 恰好一致（AA=1, DA=2），但 LH1/LH3/CD
完全漏掉了这项，导致概率偏小 n(S) 的量级（~6×10^18 倍）。

--------------------------------------------------------------------------------
2. 修改内容
--------------------------------------------------------------------------------

修改 1: AA case 简化 (L1351-1359)
  - 移除: double Gamma = (maxstick - total_state[isurf]) * ms_inv;
  - 移除: prob_value[i] = MIN(prob_value[i], 1.0);
  - 改为: prob_value[i] = 2.0 * r->k_react / Vn; (与 LH1 对齐)

修改 2: DA case 简化 (L1361-1369)
  - 同上

修改 3: 新增统一 n(S) 修正块 (L1429-1437, 在 for(j=1) 循环之前)
  if (r->type == AA || r->type == DA || r->type == LH1 ||
      r->type == LH3 || r->type == CD) {
    int n_adsorb = (int)r->coeff[3];
    prob_value[i] *= stoich_pow(maxstick - total_state[isurf], n_adsorb) *
                     pow(ms_inv, n_adsorb);
  }

修改 4: MIN 截断条件更新 (L1458-1462)
  - 移除对 AA 和 DA 的排除（因为不再在 case 内自行截断）
  - 改为只排除 D/E/R

--------------------------------------------------------------------------------
3. 概率公式对比
--------------------------------------------------------------------------------

以 LH1 O(g) + O(s) --> O2(g), coeff[3]=1 为例:

修正前:
  P = MIN(1, 2*K/Vn * N_AS*ms_inv)
      ↑ 只有显式表面物种因子，缺少 n(S)

修正后:
  P = MIN(1, 2*K/Vn * n(S)^1 * N_AS*ms_inv)
      ↑ 统一修正块     ↑ 显式表面物种
      n(S) = (maxstick-total_state)*ms_inv

与 Molchanova 2018 有限速率公式一致:
  P(Vn) = min(1, 2*K(Tw) * Γ / Vn)
  Γ_LH1 = n(S) * (N_AS * FN/Se) = 隐式空位 Γ × 显式表面物种 Γ

问题描述
================================================================================

react_gs_finite_rate() 中 L1324:
  double factor = fnum * weight[isurf] / area[isurf];
  double ms_inv = factor / max_cover;   // ← BUG: 多除了 N_site

max_cover 即 N_site（表面位点密度，m⁻²），导致：
  Γ_code = state_count × ms_inv = state_count × factor / N_site = θ × factor
  即 Γ 变成了无量纲覆盖度（0~1），而非数密度（m⁻²）。

影响范围：
  - AA (L1357): Gamma = (maxstick - total) * ms_inv → 空位点覆盖率
  - DA (L1370): Gamma = (maxstick - total) * ms_inv → 空位点覆盖率
  - LH1/LH3/ER/CD (L1444,1449): pow(ms_inv, stoich) → 覆盖率因子

正确公式（Molchanova 2018 Eq 35）:
  Γ = N × FN·w/Se  (数密度，m⁻²)
  P = 2K·Γ/Vn

定量影响:
  Γ_correct / Γ_code = N_site ≈ 6.022×10¹⁸
  P_correct / P_code = N_site ≈ 6.022×10¹⁸
  k_react 有效量纲: m/s → m³/s (需同步调整 surf 文件参数)

================================================================================
修改内容
================================================================================

L1324: double ms_inv = factor / max_cover;
   →  double ms_inv = factor;  // FIXED: no /max_cover

单行修改，所有下游引用自动修正：
  - L1357: Gamma = (maxstick - total) * ms_inv  →  N_S * FN/Se ✓
  - L1370: Gamma = (maxstick - total) * ms_inv  →  N_S * FN/Se ✓
  - L1444: pow(ms_inv, stoich)                  →  (FN·w/Se)^stoich ✓
  - L1449: pow(ms_inv, stoich)                  →  (FN·w/Se)^stoich ✓

未修改的代码：
  - react() L799: ms_inv = factor / max_cover（原始覆盖度计算，逻辑正确）
  - PS 函数 L3449: ms_inv = factor / max_cover（不在本次修复范围）

================================================================================
surf 文件参数调整注意事项
================================================================================

修复后 k_react 有效量纲从 m/s 变为 m³/s，现有 surf 文件 Arrhenius A 需调整：

  目标: 使 P = 2·K(T)·Γ/Vn 在物理合理范围（< 1，通常 << 1）

  调整方法:
  方案 A: A_new = A_old / N_site ≈ A_old / 6.022×10¹⁸
         （补偿 Γ 放大的效应，保持概率不变）

  方案 B: 从论文 K 值反算（推荐用于正式计算）
         根据 Eq (52) 的 K_ER 值（m³/s 量纲），配合已知的 Γ 和 Vn
         直接设定 Arrhenius 参数

  建议先用 tally_only yes 模式运行，观察概率大小后再调整参数。

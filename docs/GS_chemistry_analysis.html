1. 数据预处理：表面覆盖度

在进入每种反应的概率计算之前，react() 先计算一组与当前表面元素 isurf 相关的物理量。对应代码第 644–647 行。

1.1 输入符号

变量代码来源含义单位
\(F_{\text{num}}\)update->fnum每个模拟粒子代表的真实分子数—
\(\theta_{\max}\)max_cover最大覆盖度（用户指定）—
\(A_s\)area[isurf]当前表面元素的面积m²
\(W_s\)weight[isurf]当前表面元素的权重—
\(N_{\text{tot}}\)total_state[isurf]当前表面元素上吸附的总粒子数（整数）—
\(N_k\)species_state[isurf][k]表面物种 \(k\) 的吸附粒子数—

1.2 导出量（精确公式，对照代码第 644–647 行）

换算因子 \(\alpha\)（代码 factor）： \[ \alpha = \frac{F_{\text{num}} \cdot W_s}{A_s} \]
最大可吸附粒子数 \(N_{\max}\)（代码 maxstick，整数，向上取整）： \[ N_{\max} = \left\lceil \frac{\theta_{\max} \cdot A_s}{F_{\text{num}} \cdot W_s} \right\rceil \]
归一化因子 \(m_s^{-1}\)（代码 ms_inv）： \[ m_s^{-1} = \frac{\alpha}{\theta_{\max}} = \frac{F_{\text{num}} \cdot W_s}{A_s \cdot \theta_{\max}} \] ⚠ 注意：代码是 ms_inv = factor / max_cover（除以 \(\theta_{\max}\)）， 不是 factor / maxstick（除以 \(N_{\max}\)）！
表面覆盖度 \(\theta\)（代码 surf_cover）： \[ \theta = N_{\text{tot}} \cdot m_s^{-1} = N_{\text{tot}} \cdot \frac{F_{\text{num}} \cdot W_s}{A_s \cdot \theta_{\max}} \]
近似关系： \[ \theta \approx \frac{N_{\text{tot}}}{N_{\max}} \] 因为 \(N_{\max} = \lceil X \rceil\)，其中 \(X = \dfrac{\theta_{\max} \cdot A_s}{F_{\text{num}} \cdot W_s} = \dfrac{1}{m_s^{-1}}\)， 所以 \(N_{\max} \cdot m_s^{-1} = \dfrac{\lceil X \rceil}{X} \approx 1\)（大 \(X\) 时近似精确）。 因此 \(\theta = N_{\text{tot}} \cdot m_s^{-1} \approx N_{\text{tot}} / N_{\max}\)。
物理意义：\(\theta\) 是当前表面已被占据的比例。 \(N_{\max}\) 是换算到模拟粒子数层面的"座位数"。 \(m_s^{-1}\) 是每个吸附粒子对覆盖度的贡献——严格等于 \(1/X\) 而非 \(1/N_{\max}\)。

2. 反应速率常数 \(k_{\text{react}}\)

在文件读取阶段（readfile_gs() 第 2111–2114 行）预先计算好，存入 r->k_react。

2.1 SIMPLE 风格

\[ k_{\text{react}} = c_0 \] 其中 \(c_0 =\) coeff[0]，用户指定的常数概率（无量纲）

2.2 ARRHENIUS 风格

\[ k_{\text{react}} = c_0 \cdot T_w^{\,c_1} \cdot \exp\!\left(-\frac{c_2}{T_w}\right) \] 其中 \(c_0,c_1,c_2 =\) coeff[0],coeff[1],coeff[2]； \(c_2 = E_a / k_B\)，即活化能除以 Boltzmann 常数，单位 K； \(T_w =\) twall，壁面温度（恒定值，在命令行指定）。
关键局限：k_react 使用全局恒定壁温 \(T_w\) 计算，在文件读取时一次性算好，运行时不再变化。 这意味着：① 不支持壁温随时间/空间变化；② 活化能依赖壁温而非入射动能——对于有限速率催化模型而言，通常 应该用入射粒子的平动能 \(E_i = \frac{1}{2}m|\mathbf{v}|^2\) 来判断是否能克服活化能势垒。

3. 覆盖度依赖因子 \(S(\theta)\)

对于吸附介导型反应（AA, DA, LH1, LH3, CD），反应概率需乘以覆盖度依赖因子 \(S(\theta)\)。 代码提供两种模型：

3.1 简单幂律模型（无 kisliuk 标志）

\[ S(\theta) = (1 - \theta)^{\,n} \] 其中 \(n =\) coeff[coeff_val]，是覆盖度依赖的阶数。
coeff_val = 1（SIMPLE 风格）或 coeff_val = 3（ARRHENIUS 风格）。
⚠ 疑似 Bug：coeff_val 在 for 循环中按 if (r->style == ARRHENIUS) 赋值， 但 没有 else 分支归位。如果前一个反应是 ARRHENIUS，后续 SIMPLE 反应会错误地使用 coeff_val = 3 去读 coeff[3]。应补上 else coeff_val = 1;。

3.2 Kisliuk 前驱模型（带 kisliuk 选项）

Kisliuk 平衡常数（Arrhenius 形式）： \[ K_{\text{ads}} = A_K \cdot T_w^{\,b_K} \cdot \exp\!\left(-\frac{E_{a,K}}{T_w}\right) \] 其中 \(A_K, b_K, E_{a,K} =\) kisliuk_coeff[0],[1],[2]
Kisliuk 覆盖度函数（仅当 \(\theta < 1\)）： \[ S(\theta) = \left( \frac{1 - \theta}{\,1 - \theta + K_{\text{ads}} \cdot \theta\,} \right)^{\,n} \]
Kisliuk 模型的物理意义：Kisliuk 前驱模型描述了分子首先以前驱态（precursor state） 物理吸附在已占据的吸附位上，然后在表面扩散寻找空位进行化学吸附的过程。\(K_{\text{ads}}\) 是 前驱态脱附速率与化学吸附速率之比。当 \(K_{\text{ads}} = 0\) 时退化为简单幂律模型。

4. 10 种反应类型的概率计算 \(P_i\)

对入射粒子的每种可能反应 \(i\)（预存在 reactions_gs[ip->ispecies].list[] 中）， 按反应类型计算原始概率值 prob_value[i]。

4.1 非吸附介导型（无覆盖度依赖）

4.1.1 DISSOCIATION（解离）

\[ P_i = k_{\text{react}} \]

粒子命运：ip → 产物1 的气相物种，新粒子 jp = 产物2。ip 和 jp 的速度保持入射速度不变， 之后由关联的 SurfCollide 模型重新散射。

4.1.2 EXCHANGE（交换）

\[ P_i = k_{\text{react}} \]

粒子命运：ip 的物种直接改为产物物种，ip 继续存在。

4.1.3 RECOMBINATION（复合消失）

\[ P_i = k_{\text{react}} \]

粒子命运：ip → NULL（入射粒子被壁面"吃掉"）。

4.1.4 CI（Collision-Induced，碰撞诱导）

基础概率： \[ P_i = k_{\text{react}} \]
若启用 energy 选项： \[ P_i = k_{\text{react}} \cdot E_i^{\,a} \cdot (\cos\theta)^{\,b} \]
其中入射平动能与入射角： \[ E_i = \frac{1}{2} m \cdot |\mathbf{v}|^2, \qquad \cos\theta = \frac{|\mathbf{v} \cdot \mathbf{n}|}{|\mathbf{v}|} \] 其中 \(m =\) species[ip->ispecies].mass， \(\mathbf{v} =\) ip->v， \(\mathbf{n} =\) norm（表面法向量）； \(a,b =\) energy_coeff[0],[1]。
注意：CI 是唯一一个将入射粒子动能纳入概率计算的 GS 反应类型。 这一点对有限速率催化修改极具参考价值——我们可以参照此模式给吸附介导型反应也加入能量依赖。

4.1.5 ER（Eley-Rideal，气-表面碰撞反应）

⚠ 代码中有 dot = 2.0 的硬编码覆盖，实际效果等同于：
\[ P_i = k_{\text{react}} \cdot (N_{\max} \cdot m_s^{-1} - \theta) \approx k_{\text{react}} \cdot (1 - \theta) \quad (\text{当 } n_{\text{reactant}} = 1) \] \[ P_i = k_{\text{react}} \quad (\text{当 } n_{\text{reactant}} \gt 1) \] 其中 \(N_{\max} \cdot m_s^{-1} = \lceil X \rceil / X\)，\(X = \theta_{\max}A_s/(F_{\text{num}}W_s)\)， 大 \(X\) 时 ≈ 1。
原始意图 vs 代码实际： 原始代码先计算 dot = MathExtra::dot3(ip->v, norm)， 但紧接着 dot = 2.0; 将结果硬编码覆盖。 使得速度依赖完全失效。这很可能是调试过程中的临时修改，忘记恢复。

原始设计意图推测： \[ P_i = \frac{2 \cdot k_{\text{react}} \cdot (N_{\max} - N_{\text{tot}}) \cdot m_s^{-1}}{|\mathbf{v} \cdot \mathbf{n}|} \] 速度越慢的粒子在壁面附近停留时间越长，反应概率越高——这符合 Eley-Rideal 机制的物理图景。

粒子命运：ip → 气相产物，可施加 cmodel_ip 散射模型。

4.2 吸附介导型（有覆盖度依赖）

以下 5 种类型（AA, DA, LH1, LH3, CD）共享相同的概率框架：

\[ \boxed{P_i = k_{\text{react}} \cdot S(\theta)} \]

区别在于粒子命运（详见 §7）：

类型全称入射粒子命运物理意义
AAAdsorption ip → NULL 气体分子 \(\text{A(g)} \to \text{A(s)}\) 吸附在壁面
DADissociative Adsorption ip → NULL 或变成气相产物 \(\text{AB(g)} \to \text{A(s)} + \text{B(s)}\)（解离吸附）， 或 \(\to \text{A(s)} + \text{B(g)}\)（部分解离）
LH1Langmuir-Hinshelwood 类型 1 ip → 气相产物 表面物种脱附到气相：\(\text{A(s)} \to \text{A(g)}\)
LH3Langmuir-Hinshelwood 类型 3 ip → NULL 表面物种间反应生成新表面物种：\(\text{A(s)}+\text{B(s)} \to \text{C(s)}\)
CDConsumption to Bulk ip → NULL 表面物种扩散进入体相（体相消耗）
关键问题：所有 5 种吸附介导型反应的 \(S(\theta)\) 只依赖覆盖度，k_react 只依赖壁温。 对于有限速率催化，反应概率应当取决于： \[ P_{\text{reaction}} = f(E_i, T_w, \theta, \ldots) \] 其中 \(E_i\) = 入射平动能，决定粒子能否克服 \(E_a\) 势垒。 当前代码完全缺失此物理机制。

5. 表面共反应物因子

对应代码第 849–863 行。当 GS 反应涉及额外的表面相反应物（即 \(j \ge 1\) 且 state_reactants[j] == 's'），概率需乘以组合数因子：

若共反应物为催化性（part_reactants[j] == 0），使用总覆盖度： \[ P_i \;\;*\mkern-8mu{=}\;\; \binom{N_{\text{tot}}}{\nu_j} \cdot \left(m_s^{-1}\right)^{\nu_j} \]
若共反应物为参与性（part_reactants[j] == 1），使用该物种覆盖度： \[ P_i \;\;*\mkern-8mu{=}\;\; \binom{N_{s,k}}{\nu_j} \cdot \left(m_s^{-1}\right)^{\nu_j} \]

其中 \(\nu_j =\) stoich_reactants[j]（化学计量系数），\(N_{s,k}\) 为表面物种 \(k\) 的吸附量。

物理意义：对于 Langmuir-Hinshelwood 型反应（如 LH3: \(\text{A(s)}+\text{B(s)} \to \ldots\)）， GS 反应的"第一步"是气相粒子 A(g) 撞击壁面并找到已吸附的 B(s)。B(s) 的数量越多，反应概率越高。 \(\binom{N_{s,B}}{\nu}\) 表示从 \(N_{s,B}\) 个 B 中选 \(\nu\) 个的组合数，即反应"配对"的可能方式数。 \(m_s^{-1}\) 因子将粒子数归一化为覆盖度。

5.1 stoich_pow(N, k) 函数

代码第 3533–3577 行实现了二项式系数的查表计算：

\[ \texttt{stoich\_pow}(N, k) = \binom{N}{k} = \frac{N(N-1)\cdots(N-k+1)}{k!} \] 支持 \(k = 0,1,\ldots,6\)。当 \(N < k\) 时返回 0。

6. 概率归一化 & 反应抽选

代码第 865–897 行。这是 DSMC 中标准的"接受-拒绝"蒙特卡洛抽样。

6.1 求和与归一化

\[ \Sigma = \sum_{i=1}^{n} P_i \]
\[ \begin{cases} \Sigma \le 1: & \text{correction} = 1,\quad P_{\text{scatter}} = 1 - \Sigma \\[6pt] \Sigma \gt 1: & \text{correction} = \dfrac{1}{\Sigma},\quad P_{\text{scatter}} = 0 \end{cases} \]
物理意义：\(P_{\text{scatter}}\) 为"不发生任何反应，粒子直接弹性/非弹性散射"的概率。 如果所有反应的总概率超过 1，则将各反应概率等比例压缩，散射概率为 0（即粒子必然发生某种反应）。

6.2 反应抽选

Step 1: 生成随机数 \(r \sim \mathcal{U}(0,1)\)
Step 2 (散射判定): 若 \(r < P_{\text{scatter}}\)，粒子散射（无反应），返回 0。
Step 3 (反应选择): 从 \(p = P_{\text{scatter}}\) 出发，依次累加： \[ p \leftarrow p + P_i \cdot \text{correction} \] 当 \(p \gt r\) 时，选中反应 \(i\) 并执行。

等价于：选中反应 \(i\) 的概率为 \(P_i \cdot \text{correction}\)，不反应的概率为 \(P_{\text{scatter}}\)。

\[ P_{\text{scatter}} + \sum_i P_i \cdot \text{correction} \le 1 \] 当 \(\Sigma \le 1\) 时严格等于 1；当 \(\Sigma \gt 1\) 时 \(P_{\text{scatter}} = 0\)。

7. 反应执行：粒子命运 & 表面状态更新

当反应 \(i\) 被选中后（代码第 900–1131 行），做两件事：

7.1 更新表面物种计数 delta

遍历反应物（\(j = 0 \ldots n_{\text{reactant}}-1\)）和产物（\(j = 0 \ldots n_{\text{product}}-1\)）：

反应物中参与性表面物种（part_reactants[j]==1 && state=='s'）： \[ \Delta N_{k} \;\;-\mkern-5mu{=}\;\; \nu_j \]
产物中参与性表面物种（part_products[j]==1 && state=='s'）： \[ \Delta N_{k} \;\;+\mkern-5mu{=}\;\; \nu_j \]

\(\Delta N_k\) 存储在 species_delta[isurf][k]，每个 nsync 步汇总到 species_state。

催化性（part=0）和气相（state='g'）物种不改变表面计数。

7.2 粒子操作汇总

8. 完整算法流程图

┌─────────────────────────────────────────────────────────────────────────┐
│  SurfReactAdsorb::react(ip, isurf, norm, jp, velreset)                  │
│  ───────────────────────────────────────────────────                    │
│  被 SurfCollide::collide() 调用（每粒子·每步·每次壁面碰撞）                │
└─────────────────────────────────────────────────────────────────────────┘
  │
  ├─[1]────────────────────────────────────────────────────────────────────
  │  if (!gsflag) return 0;                         // GS 模式未启用
  │  if (isurf<0 && mode==SURF) ERROR;               // 模式不匹配检查
  │  if (isurf>=0 && mode==FACE) ERROR;
  │  if (mode == FACE) isurf = -(isurf+1);           // 负索引→0~5
  │
  ├─[2]────────────────────────────────────────────────────────────────────
  │  list[] = reactions_gs[ip->ispecies].list;       // 该物种的可能反应
  │  n = reactions_gs[ip->ispecies].n;
  │  if (n == 0) return 0;                           // 无反应 → 散射
  │
  ├─[3]──── 计算覆盖度 ────────────────────────────────────────────────────
  │  fnum = update->fnum;
  │  Nmax = ceil(max_cover * area / (fnum * weight));
  │  α = fnum * weight / area;
  │  ms⁻¹ = α / max_cover;        ← ⚠ 注意:除以 max_cover,不是 maxstick!
  │  θ = Ntot * ms⁻¹;             θ ≈ Ntot/Nmax (近似)
  │
  ├─[4]──── 计算各反应概率 ───────────────────────────────────────────────
  │  for each possible reaction i:
  │  │
  │  ├── 基础 k_react（已在 readfile_gs 中算好）:
  │  │   SIMPLE:      k = coeff[0]
  │  │   ARRHENIUS:   k = coeff[0] * Tw^coeff[1] * exp(-coeff[2]/Tw)
  │  │
  │  ├── 覆盖度因子 S(θ)（仅 AA/DA/LH1/LH3/CD）:
  │  │   Kisliuk:  Kads = A*Tw^b*exp(-Ea/Tw)
  │  │             S(θ) = [(1-θ)/(1-θ+Kads*θ)]^n
  │  │   简单:      S(θ) = (1-θ)^n
  │  │
  │  ├── 按类型:
  │  │   D/E/R:     P_i = k
  │  │   AA/DA/     P_i = k * S(θ)
  │  │   LH1/LH3/CD:
  │  │   ER:        P_i = k * (1-θ)     (dot被硬编码为2.0)
  │  │   CI:        P_i = k * Ei^a * cosθ^b  (可选)
  │  │
  │  └── 额外表面共反应物因子 (∀j≥1, state[j]=='s'):
  │      P_i *= C(N_ads, νj) * (ms⁻¹)^νj
  │
  ├─[5]──── 概率归一化 ────────────────────────────────────────────────────
  │  Σ = Σ P_i
  │  if (Σ > 1):  correction = 1/Σ,  Pscatter = 0
  │  else:        correction = 1,    Pscatter = 1 - Σ
  │
  ├─[6]──── 蒙特卡洛抽选 ──────────────────────────────────────────────────
  │  r = uniform(0,1)
  │  if (r < Pscatter) return 0;      // 散射，无反应
  │
  │  p = Pscatter
  │  for each reaction i:
  │    p += P_i * correction
  │    if (p > r): 选中反应 i, break
  │
  ├─[7]──── 执行反应 ──────────────────────────────────────────────────────
  │  nsingle++, tally_single[list[i]]++
  │  mark[isurf] = 1
  │
  │  // 更新表面 delta
  │  for reactants:  if (part && state=='s')  ΔN -= ν
  │  for products:   if (part && state=='s')  ΔN += ν
  │
  │  // 按类型处理粒子
  │  switch(type):
  │    D:  ip→prod[0], 新jp
  │    E:  ip→prod[0]
  │    R:  ip=NULL
  │    AA: ip=NULL
  │    DA: ip可能→气相产物, 可能有多余jp
  │    LH1: ip→气相产物, 施加cmodel_ip
  │    LH3: ip=NULL
  │    CD:  ip=NULL
  │    ER:  ip→气相产物, 施加cmodel_ip
  │    CI:  ip→气相产物, 可能+jp, 施加cmodel
  │
  └─[8]────────────────────────────────────────────────────────────────────
     return list[i] + 1;    // 1~N = 反应编号
